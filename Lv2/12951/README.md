## 문제 요약

각 단어의 첫 문자가 알파벳이면 대문자로, 나머지 알파벳은 소문자로 바꿉니다. 첫 문자가 숫자이면 그대로 두며, 원래 문자열의 공백은 연속된 공백까지 유지합니다.

전체 제한사항과 추가 예제는 원문에서 확인합니다.

## 예제

```python
solution("3people unFollowed me")
# 기대값: "3people Unfollowed Me"
```
