## 문제 요약

모든 음식의 스코빌 지수를 K 이상으로 만들기 위해 가장 낮은 두 값을 반복해서 섞습니다. 새 값은 가장 낮은 값에 두 번째로 낮은 값의 두 배를 더한 값입니다. 필요한 최소 혼합 횟수를 반환하고, 목표를 달성할 수 없으면 -1을 반환합니다.

전체 제한사항과 추가 예제는 원문에서 확인합니다.

## 예제

```python
solution([1, 2, 3, 9, 10, 12], 7)
# 기대값: 2
```
