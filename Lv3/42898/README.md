## 문제 요약

가로 m칸, 세로 n칸인 격자에서 집 (1, 1)부터 학교 (m, n)까지 오른쪽 또는 아래쪽으로만 이동합니다. puddles에 주어진 물웅덩이를 피하는 최단 경로 수를 1,000,000,007로 나눈 나머지를 반환합니다. 물웅덩이 좌표는 [가로 위치, 세로 위치]이며 1부터 시작합니다.

전체 제한사항과 추가 예제는 원문에서 확인합니다.

## 예제

```python
solution(4, 3, [[2, 2]])
# 기대값: 4
```
