## 문제 요약

begin에서 시작해 한 번에 알파벳 하나만 바꾸어 target을 만듭니다. 바꾼 단어는 매번 words에 있어야 합니다. 필요한 최소 변환 횟수를 반환하며, 변환할 수 없으면 0을 반환합니다.

전체 제한사항과 추가 예제는 원문에서 확인합니다.

## 예제

```python
solution("hit", "cog", ["hot", "dot", "dog", "lot", "log", "cog"])
# 기대값: 4
```
