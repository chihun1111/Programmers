# 이중우선순위큐

- 난이도: Lv.3
- 문제 번호: 42628
- 원문: [프로그래머스 문제](https://school.programmers.co.kr/learn/courses/30/lessons/42628)
- 연습 주제: 우선순위 큐 · 최댓값/최솟값 삭제
- 상태: 미풀이

## 문제 요약

명령에 따라 정수를 삽입하거나 최댓값 또는 최솟값을 하나 삭제합니다. "I 숫자"는 삽입, "D 1"은 최댓값 삭제, "D -1"은 최솟값 삭제이며, 빈 큐에 대한 삭제는 무시합니다. 모든 명령 처리 후 [최댓값, 최솟값]을 반환하고, 큐가 비었으면 [0, 0]을 반환합니다.

전체 제한사항과 추가 예제는 원문에서 확인합니다.

## 예제

```python
solution(["I -45", "I 653", "D 1", "I -642", "I 45", "I 97", "D 1", "D -1", "I 333"])
# 기대값: [333, -45]
```
