## 문제 요약

컴퓨터 수 n과 연결 정보를 담은 2차원 배열 computers가 주어집니다. 직접 연결되거나 다른 컴퓨터를 거쳐 연결되는 컴퓨터들을 하나의 네트워크로 보고, 전체 네트워크의 개수를 반환합니다.

전체 제한사항과 추가 예제는 원문에서 확인합니다.

## 예제

```python
solution(3, [[1, 1, 0], [1, 1, 0], [0, 0, 1]])
# 기대값: 2
```
