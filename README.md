## 진행 방법

1. Lv.0부터 표의 순서대로 풉니다. 너무 쉬운 문제는 건너뛰어도 됩니다.
2. 원문에서 제한사항을 확인하고 `solution.py`의 `pass`를 직접 구현합니다.
3. 파일을 실행해 예제 결과를 비교합니다. 예제 1개만 확인하므로 추가 입력도 직접 확인합니다.
4. 프로그래머스에서 Python3로 제출하고 채점합니다.
5. 통과하면 표의 상태를 `완료`로 바꾸고, 문제별 README에 접근 방법과 복습 메모를 적습니다.

시작 예시:

```bash
python3 Lv0/120802/solution.py
```

새로 추가한 문제는 풀이 전 결과가 `None`입니다. 풀이 틀만 제공하며 직접 구현해 연습합니다.
커밋은 한 문제 단위로 `solve: 120802 두 수의 합 구하기`처럼 남깁니다.
