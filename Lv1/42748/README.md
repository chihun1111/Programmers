## 문제 요약

각 [i, j, k] 요청마다 i번째부터 j번째까지의 구간을 정렬한 뒤 k번째 값을 구합니다. 문제의 위치 번호는 1부터 시작합니다.

전체 제한사항과 추가 예제는 원문에서 확인합니다.

## 예제

```python
solution([1, 5, 2, 6, 3, 7, 4], [[2, 5, 3], [4, 4, 1], [1, 7, 3]])
# 기대값: [5, 6, 3]
```
